How it works:
🎯 One-Click (SAM) Mode
  1. Upload an image and select One-Click (SAM) mode.
  2. Click once on the object you want to remove — SAM auto-detects it instantly.
  3. A mask overlay appears. Click again anywhere to re-detect a different object.
  4. Press Remove Object to run LaMa inpainting.
🖌️ Brush Drawing Mode
  1. Upload an image and select Brush Drawing mode.
  2. Paint over the areas you want to erase with your cursor or finger.
  3. Adjust brush size and press Remove Object to run LaMa inpainting.
